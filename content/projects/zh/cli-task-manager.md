# CLI Task Manager

A fast, terminal-based task manager that stays out of your way. Built for developers who live in the command line.

## Why CLI?

Web-based project management tools are feature-rich but slow. A CLI tool that integrates with your workflow — with vim keybindings, JSON output for scripting, and sub-100ms response times — is often more productive.

## Features

- Kanban, list, and calendar views
- Labels, priorities, and due dates
- SQLite storage — portable, no daemon required
- Git-friendly export format for sharing
- Fuzzy search across all tasks
